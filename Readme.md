# Java Demo Banking App

A console-based banking application demonstrating Factory, Builder and Command design patterns.

## Features
- User registration and login
- Bank account management (standard/premium/savings)
- Deposit, withdrawal and transfer operations
- Command pattern for console actions

## Architecture & Patterns
- Factory pattern — account types
- Builder pattern — user construction
- Command pattern — console operations

## Tech Stack
- Java 21
- JUnit 4
